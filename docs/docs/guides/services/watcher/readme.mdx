The **Morio Watcher Service** (watcher) can be utilised to run
health checks on your infrastructure.

## Watcher service responsibilities

The watcher service is a [flanking
service](/docs/reference/terminology/flanking-service), and optional.

### Run healthchecks

The purpose of the watcher service is to run healthchecks, and generate
observability data from them.

You can add your own healthchecks by _preseeding_ them from a git repository.
